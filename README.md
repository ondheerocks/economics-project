# India's Private Investment Puzzle: Still Not Picking Up?

A macroeconomic analysis presented as a professional 19-slide PowerPoint presentation.

## Overview

This project programmatically generates a polished, university-level macroeconomics presentation using the `python-pptx` library. The presentation explores why private investment in India remains selectively subdued despite strong GDP growth, examining the gap between "New Economy" sectors (semiconductors, EVs, renewables) and "Old Economy" sectors (FMCG, steel, textiles).

## How to Run

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Generate the presentation:
   ```bash
   python generate_ppt.py
   ```

3. Open `India_Private_Investment_Puzzle.pptx` with Microsoft PowerPoint, LibreOffice Impress, or Google Slides.
